# 组件说明

## Layout

全局布局组件，包含：
- 顶部导航栏（Logo、菜单导航、搜索框、功能按钮）
- 左侧边栏（个人资料、分类列表等可配置模块）
- 右侧边栏（标签云、站点信息等可配置模块）
- 分类导航栏（CategoryBar）
- 页脚

侧边栏模块通过 WordPress 后台 **Mango 主题设置 → 侧边栏管理** 进行配置，支持多种模块类型。

## CategoryBar

顶部分类导航栏，以 pill 样式显示分类列表。支持通过 WordPress 后台 **外观 → 菜单** 管理。

如果未设置菜单，则回退显示全部分类。

## PostCard

文章卡片组件，包含：
- 特色图片（或随机图片兜底）
- 文章标题、发布日期、分类标签
- 文章摘要（限制 2 行）
- 阅读更多链接

支持图片加载失败重试（最多 5 次）。

## Sidebar

侧边栏组件，分左右两侧，模块可灵活配置。支持的模块类型包括：
- 个人资料（头像、昵称、描述、社交链接）
- 分类列表
- 标签云
- 专栏列表
- 文章目录（TOC，自动解析页面标题层级）
- 关于信息
- 站点信息（运行天数、文章数等）
- 自定义 HTML
- Wiki 页面树（仅在 Wiki 详情页显示当前项目的页面层级）

## Pagination

分页组件，支持上下页翻页和页码选择。

## MarkdownRenderer

Markdown 渲染组件，用于 Wiki 页面内容的渲染。基于 `marked` 库，支持：
- GFM 语法（表格、任务列表等）
- 代码高亮（highlight.js）
- 标题自动生成锚点链接
- 复制按钮

## NativeComments

原生 WordPress 评论组件，基于 Waline 实现。支持：
- 评论列表展示（含头像、回复嵌套）
- 评论提交表单
- 分页加载

## ClickEffect

点击特效组件，在用户点击页面任意位置时显示视觉反馈动画。

## Live2D

Live2D 看板娘组件，在页面右下角显示可交互的 Live2D 角色。

## SakuraEffect

樱花飘落特效组件，为页面添加动态樱花粒子效果。

## PageTransition

页面过渡动画组件，使用 `framer-motion` 实现路由切换时的平滑过渡效果。

## WallpaperSettings

壁纸设置组件，允许用户在页面中自定义背景壁纸。
