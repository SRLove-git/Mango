# 组件说明

## Layout

全局布局组件，包含：
- 顶部导航栏（Logo、菜单导航、搜索框）
- 左侧边栏（个人资料、分类列表）
- 右侧边栏（标签云、站点信息）
- 分类导航栏（CategoryBar）
- 阅读进度条（ProgressBar）
- 页脚

## CategoryBar

顶部分类导航栏，以 pill 样式显示分类列表。支持通过 WordPress 后台 **外观 → 菜单** 管理。

如果未设置菜单，则回退显示全部分类。

## PostCard

文章卡片组件，包含：
- 特色图片（或随机图片兜底）
- 文章标题、发布日期、分类标签
- 文章摘要（限制 2 行）
- 阅读更多链接

支持图片加载失败重试（最多 5 次）。

## Sidebar

侧边栏组件，分左右两侧：

**左侧栏 (left)：**
- 个人资料卡片（头像、昵称、描述）
- 分类列表

**右侧栏 (right)：**
- 标签云
- 站点信息

## Pagination

分页组件，支持上下页翻页和页码选择。

## ProgressBar

阅读进度条，固定在页面顶部，根据当前阅读位置更新进度。
