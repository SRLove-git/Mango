# 主题设置

Mango 提供了两种内置配色方案，并支持创建自定义配色方案。

## 内置配色

| 方案 | 风格 |
| :--- | :--- |
| Anime 紫蓝霓虹 | 紫色与蓝色的霓虹氛围，深色背景 |
| 黑色简约 | 黑绿搭配简约风格 |

配色方案可通过 WordPress 后台的 **外观 → Mango 主题设置 → 主题设置** 选项卡切换，或在 WordPress 定制器（**外观 → 自定义 → Mango 主题设置**）中切换。

## 自定义配色方案

Mango 支持创建完全自定义的配色方案，可配置的 CSS 变量包括：

| 变量 | 说明 |
| :--- | :--- |
| `--bg` | 背景色 |
| `--glass` | 卡片背景色 |
| `--glass-hover` | 卡片悬停背景色 |
| `--border` | 边框色 |
| `--border-hover` | 边框悬停色 |
| `--purple` | 主色（默认 `#9b6cff`） |
| `--purple-glow` | 主色光晕 |
| `--blue` | 强调色（默认 `#4da3ff`） |
| `--blue-glow` | 强调色光晕 |
| `--text` | 正文字色 |
| `--text-muted` | 次级文字色 |
| `--text-dim` | 弱化文字色 |

## 卡片圆角

所有玻璃卡片的统一圆角大小可通过设置页面中的滑块调整（0px - 50px），默认值为 25px。

## 样式切换

主题样式通过 `body` 标签的 class 控制：

- `anime-theme` — Anime 紫蓝霓虹
- `black-theme` — 黑色简约
- `custom-theme` — 自定义配色
