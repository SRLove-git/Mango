# 主题设置

Mango 提供了 Firefly 风格的内置配色方案，并支持创建自定义配色方案。

## 内置配色

| 方案 | 风格 |
| :--- | :--- |
| Firefly 青绿暗色 | 青色/青绿色为主色调的深色模式风格 |
| 纯黑简约 | 纯黑深色简约风格 |

配色方案可通过 WordPress 后台的 **外观 → Mango 主题设置 → 主题设置** 选项卡切换，或在 WordPress 定制器（**外观 → 自定义 → Mango 主题设置**）中切换。

## 自定义配色方案

Mango 支持创建完全自定义的配色方案，可配置的 CSS 变量包括：

| 变量 | 说明 |
| :--- | :--- |
| `--bg` | 背景色 |
| `--glass` | 卡片背景色 |
| `--glass-hover` | 卡片悬停背景色 |
| `--border` | 边框色 |
| `--border-hover` | 边框悬停色 |
| `--accent` | 主题色（默认青绿色 `hsl(168, 60%, 50%)`） |
| `--accent-glow` | 主题色光晕 |
| `--text` | 正文字色 |
| `--text-muted` | 次级文字色 |
| `--text-dim` | 弱化文字色 |

## 卡片圆角

所有玻璃卡片的统一圆角大小可通过设置页面中的滑块调整（0px - 50px），默认值为 18px。

## 样式切换

主题样式通过 `body` 标签的 class 控制：

- `dark-theme` — Firefly 青绿暗色模式
- `custom-theme` — 自定义配色

## Sidebar 侧边栏管理

在 **Mango 主题设置 → 侧边栏管理** 选项卡中，可以添加和管理侧边栏模块。

每个模块可设置：

- **模块类型** — 个人资料 / 分类 / 标签云 / 近期文章 / 专栏 / 文章目录 / 关于 / 站点信息 / 自定义 HTML / Wiki 页面树
- **侧边栏** — 左侧栏 / 右侧栏
- **显示顺序** — 数值越小越靠前
- **显示在以下页面** — 控制该模块在哪些页面类型可见

### 可用模块类型

| 类型 | 说明 |
| :--- | :--- |
| `profile` | 个人资料卡片（头像、名称、简介、社交链接） |
| `categories` | 文章分类列表 |
| `tags` | 标签云 |
| `topics` | 专栏列表 |
| `toc` | 文章目录（自动解析 h1~h6 标题） |
| `about` | 预设的关于信息 |
| `site_info` | 站点信息（运行天数、文章数等） |
| `custom_html` | 自定义 HTML 代码 |
| `wiki_tree` | Wiki 页面树导航（仅在 Wiki 详情页显示当前项目的页面层级） |

## Wiki 知识库管理

在 **Mango 主题设置 → Wiki 管理** 选项卡中，可以管理 Wiki 知识库项目。

### 操作说明

1. **新建 Wiki 项目** — 点击「新建 Wiki 项目」按钮，填写项目 ID、短名称、标题、副标题、图标 URL 后保存
2. **编辑项目** — 在每个项目卡片上点击编辑按钮，可修改项目元信息
3. **添加页面** — 点击「添加页面」，填写页面 ID、标题、父页面、排序、Markdown 内容
4. **编辑/删除页面** — 在页面列表中可直接编辑或删除页面

### 数据存储

Wiki 数据存储在 WordPress 选项表 (`wp_options`) 的 `mango_wiki` 键中，通过 REST API 端点 `POST /mango/v1/wiki/save` 进行读写。

### 前台路由

- `/wiki` — 所有 Wiki 项目列表
- `/wiki/:project` — 自动跳转到该项目的第一个页面
- `/wiki/:project/:slug` — 具体 Wiki 页面内容（含侧边栏页面树导航和文章目录）
